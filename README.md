# known-or-not-found

Literature triage for a differential-expression gene list: which induced genes are established, and which weren't found.

First application: LPS-stimulated vs. unstimulated macrophages (ClawBio `rnaseq-de` → Paperclip search per gene → binned table with citations).

> "Not found" means not found in the top 25 search results for that gene's query on the search date. It does not mean novel.
